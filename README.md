# AIONOS Executive Productivity Agent (VP Sales Arjun Malhotra)

An intelligent commitment-tracking and temporal conflict-resolution engine for VP Sales Arjun Malhotra.

## Features
- **Temporal Reasoning Engine**: Resolves shifting deadlines by recency across conflicting emails, transcripts, calendars, and voice notes.
- **Silence & Stalled Detection**: Unanswered follow-ups are detected and escalated automatically.
- **Ownership Gap Alerts**: Flags urgent tasks (e.g. Mumbai office lease renewal) that lack an assigned owner.
- **Interactive Time Simulation**: Test how the briefing evolves dynamically from Mon 21 Sept to Fri 25 Sept 2026.
- **Free / Zero-Cost Architecture**: Operates without external API keys or via Groq free tier.
